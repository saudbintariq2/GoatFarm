| D30 | **Salary reconciliation is read-only.** `Finance/SalaryReconciliation` (JSON) and a panel on the Finance page appear only when there are findings. Outcomes: **Counted twice (confirmed)**: a salary-type expense or recurring cost that names someone on the Employees list while Employees salaries exist. **Needs review**: a salary-type row that names no listed employee, or a non-salary row whose comment mentions salary or advance. **Not counted twice**: any salary row when the Employees list has no salaries, because then it is the only record.
